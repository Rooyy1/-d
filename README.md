# Бизнес-игра — демо

Одна страница на HTML, CSS и JavaScript. Сервер, установка зависимостей и сборка не нужны.

## Что работает

- Замкнутое поле из 22 клеток, как на референсе: 6 столбцов и 7 строк.
- Четыре различимые фишки, пользователь управляет красной.
- Кубик от 1 до 6 и движение по клеткам по часовой стрелке.
- Автоматическая карточка при попадании на клетку категории.
- Шесть стопок по четыре тестовые карточки. Две креативные стопки имеют разные наборы.
- Карточки идут по очереди и возвращаются к первой после последней.
- Закрытие карточки кнопкой, по Escape или нажатием за её пределами.
- Правила и сброс демо. Сброс отменяет незавершённый бросок.
- Адаптивная компоновка и поддержка уменьшенной анимации.

Голосовая связь и синхронизация между разными людьми не реализованы: они требуют отдельного этапа. Положение фишки и порядок карточек хранятся только в памяти текущей страницы; обновление страницы начинает новую игру. Баллы и условия победы намеренно не добавлены.

## Как заменить карточки

Откройте `dist/cards.js`. У каждой стопки есть массив `cards`, в нём:

```js
{
  title: 'Заголовок карточки',
  text: 'Описание ситуации.',
  question: 'Вопрос для обсуждения?'
}
```

Измените текст, добавьте или удалите объекты. В каждой стопке должна остаться хотя бы одна карточка. Не меняйте `id` стопок: их использует игровое поле. После изменений обновите опубликованный сайт.

## Файлы

- `dist/index.html` — разметка.
- `dist/styles.css` — оформление и адаптивность.
- `dist/cards.js` — все карточки.
- `dist/game-engine.js` — движение и последовательность карточек.
- `dist/app.js` — управление интерфейсом и анимации.

## Локальный запуск и перенос

Можно открыть `dist/index.html` в браузере: внешних запросов и модулей нет. Для обычного статического хостинга загрузите содержимое папки `dist`, сохраняя все пять файлов рядом. В настройках сервиса используйте `dist` как выходную папку, команду сборки не задавайте.

Тексты карточек тестовые. Исходные авторские правила не восстанавливались из неразборчивого текста на фотографии.
